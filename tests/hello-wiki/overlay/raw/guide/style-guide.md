# hello-wiki 团队风格指南(滚动文档,当前 v3)

> 本文件为 faithful 整体快照:上游每次改版整体覆盖本文件;逐版本锚定请用
> 同目录 dated 派生件 style-guide.dated.md。

## 1. 问候文案

- 问候正文一律「一句话 + 无结尾句号」。
- 示例代码统一以 `greet("Hello, World")` 开场(历史遗留:v3 尚未跟进
  ADR-001 的中文默认口径,待 v4 修订)。

## 2. locales 资源

- 语言码用 BCP 47 小写短码(zh、en、fr),文件名即语言码。
- 每门语言必须在 registry.txt 登记;未登记的 .msg 文件视为死文件,评审直接打回。

## 3. 回退链纪律

- 回退链 zh → en → ascii 为冻结顺序,改动需走 ADR。
- ascii 档只允许可打印 ASCII 字符;装饰字符(emoji 等)在该档一律剥除。
